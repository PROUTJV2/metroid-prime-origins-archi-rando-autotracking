# Metroid Prime Origins Randomizer Tracker

Poptracker pack for Metroid Prime Origins Randomizer.

Comes with an autotracking feature for the Archipelago Randomizer.

## Logic

Logic expects that you know/can do:
- Bomb slots can be triggered by power bombs or bombs.
- Green missile blocks can be broken by using either Super Missiles or 5 Missiles (the item at the top of Tower of Light logically requires Super Missiles).
- Unmorphs/remorphs in tunnels.
- Easy walljumps.
- Save and Quit in specific locations that would otherwise be a softlock (Antechamber item without having collected Ice Beam for exemple).
- Some midair morphs.
Logic is currently fairly basic and trick options will be added later on.
